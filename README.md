# learn-if-demo
Nested if statement practice

## Function
This program judges whether the user can receive a gift based on age, working years and grade.
I expanded the basic case independently and added judgment logic for underage and over-age conditions.

## Knowledge points
- Nested if / elif / else
- Python indentation rules

## Problems encountered
1. Indentation errors are easy to occur, which causes mismatch of elif and else
2. Need to confirm which if the elif belongs to
